##  War Memorial Kiosk Photo Booth 📸
This project is an interactive, responsive front-end interface designed for a public-facing Selfie Kiosk at the National War Memorial. The application streamlines the user journey from "Welcome" to "Final Capture," featuring branded institutional identity and a seamless automated workflow.

# 🚀 Features
Institutional Branding: Integrated custom branding for the Trishul - Indian Defence Museum and Moradabad Nagar Nigam to ensure local administrative and historical relevance.

Automated User Journey: A multi-step interface that guides visitors through positioning, preparation, and countdown.

Responsive Design: Optimized for 9:16 vertical kiosk displays.

Seamless Deployment: Built as a standalone, high-performance HTML/CSS/JS file for ease of deployment on restricted kiosk hardware.

# 🛠 Tech Stack
Languages: HTML5, CSS3, Vanilla JavaScript.

Asset Optimization: Used Base64 encoding for logo assets to ensure rapid, offline-capable loading.

# 💡 How to Run
Clone the repository: git clone https://github.com/komal-k25/War-memorial-kiosk-UI

Open kioskscreen.html in any modern web browser.

The kiosk interface will auto-initialize in full-screen mode.
